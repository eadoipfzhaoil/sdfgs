# BnAi: چت + عکس + ویدیو با هوش مصنوعی، پلن رایگان/پولی و پنل ادمین

سایت کامل با FastAPI و دیتابیس PostgreSQL. همه چیز (کاربران، پلن‌ها، رسیدها، عکس و ویدیوهای ساخته‌شده) داخل دیتابیس Railway ذخیره می‌شود.

## امکانات
- ثبت‌نام و ورود با ایمیل
- چت هوش مصنوعی با حافظه گفتگو، ساخت عکس، ساخت ویدیو (پردازش پس‌زمینه؛ نتیجه در گالری می‌ماند)
- پلن رایگان + پلن‌های پولی با سقف روزانه
- خرید کارت‌به‌کارت: کاربر عکس رسید آپلود می‌کند، ادمین تایید یا رد می‌کند و پلن خودکار فعال می‌شود
- پنل ادمین (`/admin`): ساخت/ویرایش/غیرفعال‌کردن پلن، تایید رسید، تغییر شماره کارت و نام فروشنده، آمار، فعال‌سازی دستی پلن، مسدودکردن کاربر

## دیپلوی روی Railway
1. **مهم:** محتویات همین پوشه (`main.py`، `Dockerfile`، `requirements.txt`، `templates/` ...) باید مستقیم در **ریشه ریپوی GitHub** باشد، نه داخل یک پوشه دیگر.
2. در Railway: **New Project → Deploy from GitHub repo** (چون `Dockerfile` هست، خودش با آن بیلد می‌کند).
3. در همان پروژه: **+ New → Database → Add PostgreSQL**.
4. روی سرویس برنامه بروید → **Variables** و این‌ها را اضافه کنید:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (از گزینه Add Reference بزنید؛ اسم سرویس دیتابیس شما ممکن است فرق کند)
   - `SECRET_KEY` = یک رشته طولانی تصادفی
   - `ADMIN_EMAILS` = ایمیل خودتان (هر کس با این ایمیل ثبت‌نام کند ادمین می‌شود)
   - `AI_API_KEY` = کلید API هوش مصنوعی
   - `REPLICATE_API_TOKEN` = توکن Replicate (برای ویدیو)
   - بقیه (مدل‌ها، کارت اولیه) اختیاری است؛ `.env.example` را ببینید.
5. **Settings → Networking → Generate Domain** تا آدرس سایت ساخته شود.
6. با ایمیل ادمین ثبت‌نام کنید و به `/admin` بروید.

## نکات
- جدول‌ها در اولین اجرا خودکار ساخته می‌شوند.
- چت و عکس با هر API سازگار با OpenAI کار می‌کند (`AI_BASE_URL`, `AI_MODEL`, `IMAGE_MODEL`).
- ویدیو با Replicate است. اگر مدل شما ورودی دیگری غیر از `prompt` می‌خواهد، تابع `video` را در `ai.py` تنظیم کنید.
- اجرای محلی: `pip install -r requirements.txt` و سپس `uvicorn main:app --reload` (بدون DATABASE_URL از SQLite استفاده می‌کند).

## نصب به‌عنوان برنامه (گوشی و کامپیوتر)
سایت یک PWA است؛ بعد از دیپلوی و باز کردن آدرس سایت:
- **اندروید (Chrome):** منوی ⋮ ← «Install app» یا «Add to Home screen» (یا دکمه «⬇️ نصب برنامه» بالای سایت)
- **آیفون (Safari):** دکمه Share ← «Add to Home Screen»
- **ویندوز/مک (Chrome یا Edge):** آیکون نصب در نوار آدرس، یا منو ← «Install»
نیاز به آدرس HTTPS دارد که Railway خودش می‌دهد.

اگر فایل APK لازم دارید: بعد از دیپلوی، آدرس سایت را در pwabuilder.com بدهید تا خروجی اندروید بسازد.
